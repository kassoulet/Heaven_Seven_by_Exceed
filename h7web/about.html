Heaven Seven by Exceed

A 64k intro (Mekka & Symposium 2000). Every texture is generated at start-up from bytecode, the 3D is a software ray caster, the music is a tracker module synthesised live. Play it.

How this port works

The original x86 code was unpacked, then statically recompiled to Rust and compiled to WebAssembly; only the Win32/DirectX calls are faked. All 4181 frames and all 15.4 million audio samples match the original run in an emulator exactly. The picture is 320x240 shown at 4:3; the CRT filter is display-only.
